# Incident Response Guide

## Severity Levels

- SEV-1: Platform unavailable or critical security event.
- SEV-2: Major degradation for core chat path.
- SEV-3: Partial degradation/workaround available.

## Process

1. Declare incident and assign commander.
2. Capture timeline and request trace IDs.
3. Mitigate blast radius (rate limits, temporary feature flags).
4. Restore service.
5. Publish postmortem with corrective actions.
