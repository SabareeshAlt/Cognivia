# Skills Directory

Each `*.skill.md` file is an atomic execution playbook for common tasks in this repository.

## Usage Rule
- Select exactly one primary skill for the task.
- If needed, compose with one secondary skill only.
- Always run the skill's validation checklist before considering the task complete.

## Skill Design Contract
- Repository-specific preconditions.
- Deterministic execution steps.
- Explicit edge cases and rollback.
- Concrete examples using real files in this repository.
